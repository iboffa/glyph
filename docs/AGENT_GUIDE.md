Glyph uses UTF-8 `.gly` files, two-space blocks, no braces/semicolons. Declare functions as `name a:i64, b:i64>i64`, followed by an indented body, or `name a:i64>i64 = expression`. Use `ret value`. Entry is `main>void` or `main>i64`. Calls use `f(a, b)`. Declare locals `x:i64 = 0`; later assign `x = 1` or `x += 1`. Types: i64, f64, bool, str, [i64], [f64], [bool], [str]. No implicit conversions. Literals: 1, 1.0, true, false, "text", [1, 2]. Empty arrays need an explicit expected type.

Control: `if condition` then block, optional `else` block; `while condition` then block; `for x:array` then block. Comparisons and `and`, `or`, `not` yield Boolean values. Standard numeric precedence applies. Use `print(value)`, `len(a)`, `range(n)`, `fill(n, value)`, `clone(a)`, `push(a, value)`. `fold a 0 +` sums a numeric array in order; `fold a 1 *` multiplies. Parenthesize fold inside other expressions. `i64(x)` and `f64(x)` are explicit conversions. `argi(0)` reads the first integer program argument.

Integers and array access trap on overflow/out-of-bounds. Array assignments share storage; clone explicitly copies. Allocations live until exit. No shadowing. All non-void return paths must return. No imports or user generics. Avoid unsafe unless needed: `ptr`, `offset`, `load`, `store` require an `unsafe` block and valid array-derived pointers.

Use `glyph check file.gly --json`, `glyph build file.gly -O2`, `glyph run file.gly -- 10`, `glyph fmt file.gly`. Diagnostics contain code, message, file and one-based spans. Fix the first error and recheck. Verify program outputs before claiming completion.
